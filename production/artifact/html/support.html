این توضیحات دربارهٔ سایت و استودیوی طراحی هما در myhoma.ir است.

استودیو چه کاری انجام می‌دهد؟

عکس فضای خود و خواسته‌هایتان را وارد می‌کنید. هما از سرویس‌های هوش مصنوعی برای طراحی، جست‌وجوی محصولات و در صورت انتخاب، تولید تصویر استفاده می‌کند. نتیجه می‌تواند شامل پیشنهاد چیدمان، محصولات و تصویر طراحی باشد.

برای اصلاح طرح یا پرسیدن سؤال، از بخش گفت‌وگوی همان طراحی استفاده کنید. شروع یک درخواست تازه ممکن است زمان و اعتبار مصرف کند.

درخواست متوقف شده یا نتیجه ناقص است؟

پیام خطا، شناسهٔ پیگیری یا لینک گفت‌وگو و زمان تقریبی درخواست را به ایمیل پشتیبانی بفرستید. شناسهٔ پیگیری کمک می‌کند همان مرحله بررسی شود. پیش از ارسال دوباره، وضعیت درخواست قبلی و اعتبار حساب را ببینید.

تماس امن با پشتیبانی

به FARBOD.LOTFI@PARSMEHRAGRO.COM ایمیل بزنید. اگر از صفحه عکس می‌فرستید، اطلاعات شخصی را بپوشانید. رمز، کد ورود، کلید API یا اطلاعات بانکی نفرستید.

پیش از خرید محصول

تصویر طراحی پیش‌نمایش است. ابعاد، رنگ، گونهٔ انتخابی، قیمت نهایی، موجودی و شرایط ارسال یا مرجوعی باید پیش از خرید بررسی شوند. قیمت هر اندازه از یک محصول می‌تواند متفاوت باشد.
